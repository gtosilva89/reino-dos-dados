# Reino dos Dados

RPG em pixel art para aprender banco de dados, criado para a UC2 "Implementar banco de dados" do curso Programador de Sistemas (Senac PR).

**Jogar:** https://gtosilva89.github.io/reino-dos-dados/

## Como funciona
- 4 níveis (Fácil, Médio, Difícil e Expert), cada um com 4 regiões que formam um mapa só.
- Cada região começa com uma história que ensina o conteúdo: da planilha ao banco, SGBD, tabelas, chaves, MER, normalização, SQL, Python + banco, permissões e backup.
- Batalhas com perguntas, missões, chefões em equipe, XP, níveis e selos.
- Som 8 bits gerado no navegador (botões Efeitos e Música no topo).
- O progresso fica salvo no navegador e vai sozinho para a planilha do professor.
- "Já joguei em outro computador": digite o seu nome para continuar de onde parou.
- Área do Professor (com senha) na tela inicial.

Alguns lugares e níveis abrem com um código que o professor fala em aula.

Arquivo único (`index.html`), sem instalação: também funciona abrindo o arquivo direto no computador.
